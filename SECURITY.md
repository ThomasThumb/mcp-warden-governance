# Security Policy

## Supported Versions

This project is pre-1.0. Security fixes target the default branch and the
latest tagged release once public releases begin.

## Reporting a Vulnerability

Please report security vulnerabilities privately by opening a GitHub Security
Advisory in this repository. If advisories are not yet enabled, contact the
maintainer privately and avoid posting exploit details in public issues.

Include:

- affected component (`warden-cp`, `mcp-warden`, deployment scripts, or docs)
- reproduction steps or proof of reachability
- expected security invariant
- impact and required privileges
- any logs or scanner output that do not contain secrets

## Safe Harbor

Good-faith research is welcome when it avoids data destruction, persistence,
service disruption, credential theft, and access to other users' data.
